# 💰 TrackWise — Full-Stack Expense Tracker (MERN Stack)

**TrackWise** is a secure and intuitive full-stack expense tracking application built using the **MERN stack**.  
It enables users to manage their income and expenses efficiently, visualize spending patterns through interactive charts,  
and export financial reports to Excel for detailed analysis.

---

## 🚀 Features

### 💼 Core Functionalities
- 💳 **Expense & Income Management** – Add, update, and delete income and expense entries with complete CRUD support.
- 🔐 **Secure Authentication** – Implemented **JWT-based authentication** and **bcrypt encryption** to ensure secure user sessions.
- ⚙️ **RESTful API Architecture** – Designed 6+ distinct APIs to handle transactions, users, and reports with robust validation.
- 📊 **Visual Analytics Dashboard** – Interactive **Bar**, **Pie**, and **Line** charts for real-time financial insights and spending breakdowns.
- 📁 **Excel Export Feature** – Generate detailed financial reports in Excel format using **ExcelJS**.
- 📱 **Responsive UI** – Built using **React.js** and **Tailwind CSS**, ensuring seamless performance across all devices.

---

## 🧠 Tech Stack

**Frontend:**
- React.js, Tailwind CSS

**Backend:**
- Node.js, Express.js, MongoDB, Mongoose

**Authentication & Security:**
- JWT, bcrypt

**Data & Visualization:**
- ExcelJS (export reports)
- Chart.js / Recharts (data visualization)
